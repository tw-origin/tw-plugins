# TW Plugins

Official plugin registry for TW Framework.

## Available Plugins

### tw-analytics
Lightweight page view analytics. Injects a tracking snippet into every built HTML page.

## Usage

```bash
tw plugin add tw-analytics
tw plugin list
```

## Creating Your Own Plugin

1. Create a directory with `manifest.json` and `index.js`
2. Register it in `registry.json`
3. Submit a PR to this repo
